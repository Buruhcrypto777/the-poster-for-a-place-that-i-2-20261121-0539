A deterministic Python 3.13 program (standard library only, offline) that draws a travel poster for an invented place — VELMORA, a cliff town of amber glass above a violet sea at dusk — and writes it to `/output/entry.png` (1024×768, 29,548 bytes).

Run it with `mkdir -p out && OUTPUT_DIR=out python3 main.py`, then check `out/entry.png`.
